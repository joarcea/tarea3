# Tarea 3 - Cajas Responsivas

Este proyecto implementa un diseño de cajas responsivas que se adapta a diferentes tamaños de pantalla.

## Características

- ✨ Diseño responsivo con CSS Grid
- 🎨 6 cajas con colores únicos y gradientes
- 📱 Se adapta a móviles, tablets y escritorio
- 🎭 Efectos hover con transiciones suaves
- 🌈 Diseño moderno con gradientes y sombras

## Estructura del Proyecto

- `index.html` - Estructura HTML del sitio
- `styles.css` - Estilos CSS con diseño responsivo

## Diseño Responsivo

- **Desktop (> 1400px)**: 3 columnas
- **Tablet (768px - 1400px)**: 2 columnas
- **Mobile (< 768px)**: 1 columna

## Cómo Visualizar

1. Abre `index.html` en tu navegador
2. O usa un servidor local:
   ```bash
   python3 -m http.server 8000
   ```
3. Navega a `http://localhost:8000`
