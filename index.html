1. Diseño Web Responsivo

Es una técnica de diseño web que permite que las páginas se adapten automáticamente a diferentes tamaños de pantalla y dispositivos (móviles, tablets, desktops).

Importancia actual (2026): Con el aumento del tráfico móvil (>65%), mejora la experiencia del usuario (UX), reduce la tasa de rebote, favorece el SEO (Google prioriza mobile-first) y ahorra costos al evitar sitios separados.

Principios básicos: Layouts fluidos, imágenes flexibles, media queries y enfoque mobile-first.

2. El Viewport

El viewport es el área visible de la página en el navegador del dispositivo. En móviles, sin configuración adecuada, el navegador muestra el sitio como si fuera de 980px de ancho y hace zoom out.

Configuración esencial:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Esto fuerza al navegador a usar el ancho real del dispositivo y un zoom inicial de 1:1, esencial para diseños responsivos.

3. CSS3 Media Queries

Son reglas CSS que aplican estilos condicionales según características del dispositivo (ancho, altura, orientación, resolución).

Ejemplos prácticos:

  • @media (max-width: 768px) { ... } → Para móviles
  • @media (min-width: 992px) { ... } → Para desktops
@media (max-width: 992px) {
  .main-layout { flex-direction: column; }
}
@media (max-width: 768px) {
  .images { grid-template-columns: 1fr; }
}

En esta página usamos media queries para apilar columnas y cambiar el grid de imágenes en móvil.

4. Bootstrap 5

Bootstrap 5 es un framework CSS/JS open-source mobile-first que acelera el desarrollo de interfaces responsivas con componentes pre-diseñados.

Componentes usados aquí:

  • Containers: .container para centrar contenido.
  • Grid System: row + col-* para layouts flexibles (12 columnas, breakpoints sm/md/lg).
  • Flex: d-flex, align-items-center para alinear elementos.
  • Carousel: Slider interactivo para mostrar contenido dinámico.
  • Navbar: Barra de navegación colapsable en móvil.

En esta versión actualizada, Bootstrap hace el sitio más profesional y responsivo automáticamente.
